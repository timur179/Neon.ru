NEON VAULT — личный маркетплейс HTML-шаблонов (демо)

Запуск:
1. Распакуйте архив.
2. Откройте index.html в современном браузере.

Работает в демо:
- переключение экранов без перехода по длинной странице;
- поиск и фильтры каталога;
- карточки с предпросмотром;
- интерактивная корзина;
- 15 визуальных режимов;
- 25 цветов;
- светлая и тёмная темы;
- настройки темы сохраняются в localStorage браузера.

Важно:
Это фронтенд-демо, не защищённый личный кабинет. Не размещайте его как приватный сервис без серверной авторизации.
Оплата и выдача ZIP не подключены; реальные шаблоны в каталоге пока демонстрационные.
Для настоящего закрытого магазина потребуется серверная авторизация, хранение файлов вне публичной папки, платёжный провайдер и безопасная выдача файлов после подтверждённой оплаты.
